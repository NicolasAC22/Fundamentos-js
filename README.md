# Fundamentos de JavaScript

## Descripción

Este proyecto contiene 21 ejercicios prácticos para aprender y practicar los fundamentos de JavaScript.

## Objetivos

* Comprender el uso de variables y tipos de datos.
* Realizar operaciones matemáticas y lógicas.
* Utilizar estructuras condicionales y bucles.
* Crear y utilizar funciones.
* Trabajar con arrays.
* Manipular elementos HTML mediante JavaScript.

## Tecnologías utilizadas

* HTML5
* CSS3
* JavaScript

## Estructura

Cada ejercicio dispone de su propia carpeta con los archivos necesarios para ejecutarlo.

## Ejecución

Los ejercicios que utilizan elementos del navegador se ejecutan abriendo su archivo `index.html` en un navegador web.

Los scripts compatibles con Node.js pueden ejecutarse desde la terminal con el comando `node`, seguido de la ruta del archivo JavaScript.
